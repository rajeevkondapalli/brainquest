# BrainQuest - Knowledge Survival Game

A simple terminal-based knowledge survival game. Answer questions correctly to survive!

## How to Run

```bash
npm start
```

Or in development mode with auto-reload:

```bash
npm run dev
```

## Game Rules

- Answer multiple choice questions (1-4)
- Get a question right to continue
- Get a question wrong and you lose
- Survive all questions to win!
